# Book Manager

A WordPress CRUD Plugin built to learn WordPress Core.

## 📖 About

Book Manager is not just another CRUD plugin.

It is a learning project designed to understand how WordPress works internally while building a real-world plugin.

Every feature is implemented step by step, and every WordPress API is explored by reading the WordPress Core source code.

## 🎯 Goals

- Learn WordPress Plugin Development
- Learn Object-Oriented PHP (OOP)
- Learn WordPress Database API (`$wpdb`)
- Learn CRUD Operations
- Learn WordPress Hooks
- Learn WordPress Security (Nonce & Capability)
- Learn WordPress Admin Pages
- Learn AJAX
- Learn REST API
- Read and understand WordPress Core

## 🚀 Learning Philosophy

Each lesson follows the same process:

```
Experiment
    ↓
Prediction
    ↓
Implementation
    ↓
Testing
    ↓
WordPress Core Investigation
    ↓
Conclusion
```

The objective is not only to make the plugin work, but also to understand **why** it works.

## 🛠 Requirements

- PHP 8.1+
- WordPress 6.0+
- Composer

## 📦 Installation

```bash
git clone <repository-url>
cd book-manager
composer install
```

Copy the plugin into the `wp-content/plugins` directory and activate it from the WordPress Admin Dashboard.
